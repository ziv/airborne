# Instructions for LLM that reviewing this codebase

## Math

* The use of the operator `*` for multiplication of matrices is correct. The results is a matrix.
* The use of the operator `*` for multiplication of a matrix and a vector is correct. The result is a vector.
* The use of the operator `*` for multiplication of a scalar and a vector is correct. The result is a vector.
* The use of the operator `*` for multiplication of a scalar and a matrix is correct. The result is a matrix.
