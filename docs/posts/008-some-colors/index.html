Some Colors

2026-03-27

In this post we will continue to build our world by adding some colors to it.

First, I owe you a better render of the results from the previous post. I was not happy with the way the terrain looked in the previous post, so here it is again:

Since the original game is always in the back of my mind, I wanted to keep the same color palette as the original game. So i tried to mimic the way height being colored back in the 80’s.

The color scheme was pretty simple, blue for the sea, green/yellow for the land, and gray/brown for the mountains (mostly).
