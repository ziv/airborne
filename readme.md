# Airborne

This is a project to make a little bit modern version of the
classic [F-15 Strike Eagle II](https://en.wikipedia.org/wiki/F-15_Strike_Eagle_II) and others flight simulators
made by the legendary [MicroProse](https://en.wikipedia.org/wiki/MicroProse).

The magic of those games comes from the fact it is not really simulator, and it is not really an arcade. It somthing
between.

## Nostalgia Moment

I spent so many hours flying this machine on my XT-16MGhz machine with CGA screen.
